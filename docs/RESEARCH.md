# Source research, 2026-10-16

Six public projects were cloned into `/tmp/mika-research` and their relevant implementations inspected. The bot uses its own integration code and pinned dependencies; no implementation was copied into this repository.

Additional review for the owner's direct-link reports: [Castbox Downloader](https://github.com/mosayeb-a/castbox-downloader) uses an episode ID API that returned HTTP 404 for the supplied current episode, while [CastBox_Downloader](https://github.com/EhsanShahbazii/CastBox_Downloader) uses a browser to observe audio network requests. The current implementation instead uses the episode title in Castbox's canonical public URL and requires one exact public Apple Podcasts enclosure. [yt-dlp-community-plugin](https://github.com/biggestsonicfan/yt-dlp-community-plugin) provides a YouTube community-post image extractor; pinned to the tested commit, it returned nine and three ordered photos for the owner's two samples, and both batches reached Telegram. Upstream [yt-dlp TikTok sound issues](https://github.com/yt-dlp/yt-dlp/issues/8879) show the music-page extractor can fail; soundtracks exposed alongside public photo posts are processed through the post fallback instead.

The dependency itself can change behavior as source sites change. Public catalog pages do not provide Spotify, Apple Music, or Deezer licensed full audio. This project resolves a catalog item, searches public recordings, and automatically sends only a strict title, artist, and duration match. It does not claim those files came from the catalog service. ISRC is retained when exposed by catalog APIs but is rarely available in public recording metadata. No candidate is fabricated to fill a results page.

`gallery-dl` may require a valid user session for some otherwise public Instagram stories, highlights, and profiles. No session cookies were supplied. This remains a source access constraint, not evidence that those downloads work anonymously.
