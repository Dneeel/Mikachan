# موجودی دستورهای Mikachan V2 — نسخه Notes & Rules جدید

منبع: بررسی مستقیم `src/mikachan/bot.py`, `utilities.py`, `community.py`, `groupstatus.py`, `settings_ui.py`, `userbot.py`, `cli.py` در بستهٔ اصلاح‌شده. این فهرست عمداً **منوی BotFather** را با **دستورهای واقعاً قابل اجرا**، **دستورهای رزرو/غیرفعال**، **عبارت‌های فارسی بدون اسلش** و **فرمان‌های CLI سرور** یکی نمی‌گیرد.

## A. دستورهای واقعاً متصل به مسیر اجرا (پس از حذف دستورهای قدیمی)

> تمام دستورهای عادی همچنان تابع سیاست دسترسی Owner/USER/Admin، allowlist و مجوز گروه هستند. دستورهای گروه به بات دارای دسترسی مدیریت و عضویت معتبر نیاز دارند. بسیاری از دستورها عمداً در BotFather ثبت نیستند ولی با تایپ قابل فراخوانی‌اند.

## B. دستورهای زمینه‌ای و نام‌های موجود ولی غیرفعال/رزرو شده

| دستور | وضعیت واقعی |
|---|---|
| `/cancelsettings` | **فعال فقط در جریان ورود پاسخ تنظیمات**؛ درخواست جاری Settings را لغو می‌کند، دستور عمومی منو نیست |
| `/rate` | فرمان عمومی حذف‌شده؛ مسیر تشخیص قیمت و ارز بدون اسلش جداگانه برقرار است |
| `/start` | در Dispatcher حاضر **Handler اختصاصی ندارد** |
| `/cancel` | Handler مستقل ندارد؛ Cancel دانلود از طریق دکمه در `/queue` است |
| `/joke` | رزرو/غیرفعال؛ آرشیو محتوای معتبر تعریف نشده |
| `/time` | کد قدیمی موجود است ولی از `Utilities.command()` خارج شده است |
| `/apod` | نام تاریخی مستندات، ولی Dispatcher آن را اجرا نمی‌کند؛ نام فعلی `/nasa` است |
| `/image` | کد قدیمی تبدیل فایل وجود دارد ولی مسیر عمومی آن غیرفعال است |
| `/sticker` | پیاده‌سازی قدیمی بلااستفاده و غیرفعال؛ جایگزین عمومی جدید `/st` است |
| `/stickerimage` | پیاده‌سازی قدیمی بلااستفاده و غیرفعال؛ جایگزین عمومی جدید `/xst` است |
| `/gif` | کد قدیمی تبدیل TGS به GIF موجود ولی دستور عمومی غیرفعال است |
| `/pack` | کد قدیمی مدیریت Sticker Pack موجود ولی دستور عمومی غیرفعال است |
| `/convert` | کد قدیمی تبدیل CSV/JSON موجود ولی دستور عمومی غیرفعال است |

دستورهای `/admin`، `/setcmd` و `/delcmd` در Dispatcher وجود ندارند. نوت‌های گروه با کلمهٔ دقیق (بدون اسلش) اجرا می‌شوند. `/note` و `/delnote` قدیمی هم دیگر Handler ندارند؛ حذف/ویرایش از منوی `/notes` انجام می‌شود. داده‌های تاریخی Custom Commands فقط در دیتابیس قدیمی باقی می‌مانند و دیگر اجرا نمی‌شوند.

## C. تریگرهای فارسی و انگلیسی بدون اسلش

| ورودی | اثر |
|---|---|
| `قوانین` | ارسال قوانین گروه در صورت ثبت‌شدن؛ در نبود قوانین سکوت |
| `هشدار` (مثال) | ارسال نوت تعریف‌شده برای همان کلمه، فقط در همان گروه |
| `عکس به استیکر` | روی عکس/فایل تصویری ریپلای‌شده معادل `/st` |
| `استیکر به عکس` | روی استیکر ریپلای‌شده معادل `/xst` |
| `فال` | `/fal` |
| `شعر` | `/poem` |
| `هواشناسی`، `هواشناسی CITY` | `/weather` |
| `اکنون`، `اکنون CITY` | `/now` |
| `ارز` | کارت خلاصهٔ بازار |
| `ارز ...` | مسیر داخلیِ استعلام دارایی، بدون نمایش دستور `/rate` |
| `دلار`، `100 usd`، `2300 jpy to usd`، `تتر به لیر`، `12 xrp to eur` و سایر الگوهای تعریف‌شده | Userbot → CoinPJ در صورت راه‌اندازی؛ در بعضی ورودی‌ها fallback داخلی بازار |
| `آمار`، `آمار روزانه`، `آمار هفتگی`، `آمار ماهانه`، `آمار سالانه`، `آمار 365 روزه`، `آمار سال تقویمی`، `آمار کل` | منو/بازه‌های `GroupStatus` در گروه‌های مجاز |
| لینک عمومی پشتیبانی‌شده بدون دستور | پنل Profile/Follow یا تأیید دانلود؛ مطابق سیاست دانلودر |

عبارت‌های ارزی از Regex صریح `userbot.py` استخراج می‌شوند؛ هر متن تصادفیِ حاوی کلمه «دلار» تریگر نیست. تصویر بدون متن با فرمان در کپشن `/st` یا «عکس به استیکر» نیز پردازش می‌شود.

## D. فهرست واقعی BotFather Menu

در `App.run()` **29 دستور** در `set_my_commands()` ثبت می‌شوند:

`/help`, `/search`, `/music`, `/podcast`, `/twitter`, `/instagram`, `/tiktok`, `/youtube`, `/follow`, `/following`, `/settings`, `/queue`, `/status`, `/fal`, `/poem`, `/dice`, `/rules`, `/groupstatus`, `/notes`, `/qr`, `/url`, `/scan`, `/ocr`, `/tr`, `/pron`, `/asr`, `/style`, `/ai`, `/st`, `/xst`, `/weather`, `/now`, `/nasa`.

در منوی BotFather نام‌های فارسی قابل ثبت به‌عنوان Slash Command نیستند؛ عبارت‌های فارسی با متن عادی پشتیبانی می‌شوند. ثبت دستورها در `App.run()` فقط **پس از اجرای نسخهٔ جدید روی سرور** رخ می‌دهد.

## E. فرمان‌های خط فرمان سرور — نه دستورات Telegram Chat

ورودی `mikachan` بر اساس `src/mikachan/cli.py` چهار حالت دارد: `run`, `doctor`, `import-content PATH`, `userbot-login`. همچنین بستهٔ مدیریتی سرور از طریق `mikachan` launcher / `deploy/manage.sh` به منوی Terminal Manager وصل می‌شود؛ این دو دسته دستورات را نباید با پیام‌های `/...` در تلگرام اشتباه گرفت.

## F. فایل‌های اصلیِ مستندکنندهٔ رفتار

- `src/mikachan/bot.py` — Dispatcher، مجوزها، فرمان‌های عمومی، منوی BotFather و Queue
- `src/mikachan/community.py` — مدیریت گروه و کنترل مجوزهای بات
- `src/mikachan/group_content.py` — نوت‌ها، قوانین، ذخیره نسخه اصلی پیام و منوهای مدیریتی
- `src/mikachan/utilities.py` — فرمان‌های Utility، داخلی قیمت و `/st`/`/xst`
- `src/mikachan/sticker_tools.py` — اعتبارسنجی تصویر و خروجی WebP/PNG
- `src/mikachan/groupstatus.py` — عبارت‌های آمار فارسی
- `src/mikachan/settings_ui.py` — `/cancelsettings` در ورودی تنظیمات
- `src/mikachan/userbot.py` — Regex دقیق Queryهای ارزی و Photo Relay
- `src/mikachan/cli.py` — CLI سرور

## G. محدودیت‌های تأیید

تبدیل تصویر و استخراج فریم WebM با تست آفلاین بررسی شدند، اما ارسال زندهٔ استیکر و PNG از طریق Bot API و رندر واقعی TGS روی VPS در این محیط تأیید نشده است. سایر دستورهای قدیمی براساس **مسیر اجرایی فعلی** طبقه‌بندی شده‌اند، نه ادعاهای نسخه‌های تاریخی مستندات.
