Media downloads and downloader internals were not redesigned for this settings work. Existing jobs drain when Downloader is switched off; new requests are stopped. Follow polling pauses when switched off. Suspended/revoked people lose interactive access immediately; queued jobs are cancelled and active tasks are cancelled when the change is applied through the Telegram settings panel. Follow subscriptions are removed on the next monitor pass after revocation.

The next settings increment should implement the shared versioned Message Studio and scoped welcome/goodbye/rules media capture, then filters, reminders, Known Members controls and operational measurement. No placeholder button claims those features work now.
