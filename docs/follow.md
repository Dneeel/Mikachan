# Public profile Follow

`/follow instagram|twitter|youtube|tiktok HANDLE` or `/follow PROFILE_URL` opens a confirmation panel. `/instagram @handle`, `/twitter @handle`, `/youtube @handle`, and `/tiktok @handle` open the profile action panel. A profile URL sent as a normal link opens that panel directly. Where public profile metadata exposes an avatar, the panel is sent as a photo with name and bio; when the source blocks it, the panel remains available as text. A **Profile** button appears on Instagram, TikTok, YouTube, and X post confirmations before download and on delivered media afterward. The panel offers Follow, a profile link, recent public content, and platform-specific actions. Creator lookup uses the post URL where possible and bounded public metadata inspection for Instagram and YouTube. If anonymous metadata is blocked, the bot reports that it cannot identify the creator rather than showing an unrelated profile. `/following` lists subscriptions; each profile can be edited, checked immediately, or unfollowed, and the menu can be closed.

The user chooses event categories, delivery as queued media or a notification with Link and Download, and (when started in an allowed group) a private chat or that group. Private chat is the default. The first successful check for each category records a baseline and does not send old content. Subsequent checks run about every 15 minutes in a single background task; one user can follow at most 25 profiles. SQLite stores subscriptions, category baselines, event IDs, and short download tokens. The task does not download media until a new event occurs or the user presses Download.

The sources are public `gallery-dl` metadata for Instagram, TikTok, and X, and `yt-dlp` flat channel listings for YouTube videos and Shorts. Structured public profile data is required for bio, display name, and avatar changes. The public page's Open Graph description is **not** used as a bio because it can include changing follower counts. Profile changes are reported as text. Anonymous source access can fail; after three failed checks the user receives a warning, and checks continue. Category checks are independent: an inaccessible timeline does not stop profile-change checks, and the user receives a separate warning if one category fails three times. Revoked users and disabled groups lose their subscriptions.

Instagram and TikTok stories are best effort. The profile Stories action browses public story items and offers individual downloads; it does not queue a story-list URL as media. The public extractors may require login or omit stories, so a missed story cannot be ruled out. Reliable Instagram/TikTok live start and username change alerts are not implemented: no stable public, anonymous source was verified. A shorter poll interval would consume more resources without solving unavailable live signals. Private profiles and credentials are outside this feature.

Run `pytest -q tests/test_follow.py tests/test_reported_regressions.py` for parser, ownership, baseline, deduplication, delivery mode, settings edits, story links, and immediate checks. A local read-only smoke check retrieved 14 public NASA X posts and structured profile fields using the production `public_items` and `public_profile` functions. TikTok profile Open Graph metadata and its avatar were accessible, but its public story listing returned 403. Instagram was rate-limited with 429, and YouTube was blocked by this environment's network proxy; those platforms still need acceptance on an accessible deployment.
