# Public profile Follow

`/follow instagram|twitter|youtube|tiktok HANDLE` or `/follow PROFILE_URL` opens a confirmation panel. `/instagram @handle`, `/twitter @handle`, `/youtube @handle`, and `/tiktok @handle` open the profile action panel. A profile URL sent as a normal link opens that panel directly. Where public profile metadata exposes an avatar, the panel is sent as a photo with name and bio; when the source blocks it, the panel remains available as text. A **Profile** button appears on Instagram, TikTok, YouTube, and X post confirmations before download and on delivered media afterward. The panel offers Follow, a profile link, recent public content, and platform-specific actions. Creator lookup uses the post URL where possible and bounded public metadata inspection for Instagram and YouTube. If anonymous metadata is blocked, the bot reports that it cannot identify the creator rather than showing an unrelated profile. `/following` lists subscriptions; each profile can be edited, checked immediately, or unfollowed, and the menu can be closed.

The user chooses event categories, delivery as queued media or a notification with Link and Download, and (when started in an allowed group) a private chat or that group. Private chat is the default. New post notices offer a direct Link, Download, Profile panel, and Thank you to dismiss. Profile-change notices show the new text or avatar-change label, Link, Profile panel, and Thank you; avatar notices also offer a profile-photo fetch. Notification and `/following` buttons are bound to the original numeric user ID, chat, and message. The first successful check for each category records a baseline and does not send old content. Subsequent checks run about every 15 minutes in a single background task; one user can follow at most 25 profiles. SQLite stores subscriptions, category baselines, event IDs, and short download tokens. The task does not download media until a new event occurs or the user presses Download.

The sources are public `gallery-dl` metadata for Instagram, TikTok, and X, and YouTube's public RSS feed for videos with a `yt-dlp` fallback; Shorts use a flat listing. TikTok post listings also try the public `yt-dlp` user extractor when `gallery-dl` fails. X text-only tweets are enabled explicitly. A previously populated timeline that abruptly returns empty is counted as a source failure. Structured public profile data is required for bio, display name, and avatar changes. TikTok's signed avatar CDN URL is excluded from change detection; a stable provider avatar ID is used when present. The public page's Open Graph description is **not** used as a bio because it can include changing follower counts. Profile changes are reported as text. Anonymous source access can fail; after a failed full check the user receives a throttled warning, and checks continue. Category checks are independent: an inaccessible timeline does not stop profile-change checks. **Check now** reports which selected public sources were accessible. Revoked users and disabled groups lose their subscriptions.

Instagram and TikTok stories are best effort. The profile Stories action browses public story items and offers individual downloads; it does not queue a story-list URL as media. Failed story checks are kept as status without an automatic account-change warning. The public extractors may require login or omit stories, so a missed story cannot be ruled out. Reliable Instagram/TikTok live start and username change alerts are not implemented: no stable public, anonymous source was verified. A shorter poll interval would consume more resources without solving unavailable live signals. Private profiles are outside this feature. Instagram can block anonymous access to public items. Operators may set `MIKACHAN_INSTAGRAM_COOKIES_FILE` to an absolute path outside the repository for a Netscape-format cookie file from their own account, owned by the bot user with mode 0600. The file is passed only to Instagram extractors. Expired cookies, rate limits and inaccessible stories can still interrupt monitoring; never commit the file or send it through Telegram.

Run `pytest -q tests/test_follow.py tests/test_reported_regressions.py` for parser, ownership, baseline, deduplication, delivery mode, settings edits, story links, and immediate checks. An earlier local read-only smoke check retrieved 14 public NASA X posts and structured profile fields. On 2026-10-19, anonymous `gallery-dl` requests for `@truereinhard` posts, stories, and avatar returned 403 from this environment; the alternative public TikTok endpoint also returned 403. This is a source-access failure, not a profile change. Instagram and YouTube still need acceptance on a deployment with source access.
