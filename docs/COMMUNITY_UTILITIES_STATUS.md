## Runtime setup and inputs

`BOT_TOKEN`, `OWNER_TELEGRAM_ID`, `ALLOWED_TELEGRAM_IDS` remain required environment seeds. `ALLOWED_GROUP_IDS` seeds approved negative numeric group IDs on first database initialization. Effective OWNER/ADMIN/USER, group and status permissions now come from persisted SQLite registry state; ADMIN and USER never receive incoming private-chat service. The Owner uses private `/settings` to register named IDs and groups. `PRIVATE_CHATS_ONLY` is retained for manager compatibility and does not override this effective role policy. `MOMMY_TELEGRAM_IDS` is optional and currently must be a subset of the configured seed IDs. `NASA_API_KEY` defaults to NASA's limited `DEMO_KEY`. `NAVASAN_API_KEY` optionally enables its timestamped direct feed; `NAVASAN_REFRESH_SECONDS` defaults to 28,800 to respect the published 120/month free tier in a continuously running process. `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` and the secret `COINPJ_SESSION` are optional inputs for the CoinPJ user client. OCR and translation now use the optional configured userbot through @OCRnerdBOT and @UtilHubBot; no translation HTTP provider or Tesseract host dependency is used. `/admin provider fiat frankfurter|open_er_api` and `/admin provider crypto coingecko|coinpaprika` choose fixed global reference sources in the Owner's private chat.

A reviewed content import is a JSON array of objects with nonempty `kind` (`poem`, `quote`), `language`, `body`, `author`, `source`, and `rights`. The owner/operator must verify permission and attribution before import; the tool validates required fields and size, not intellectual property rights. For Hafez fortune, set `author` to `Hafez`, `Hafez Shirazi`, `حافظ`, or `حافظ شیرازی`. Content and settings survive normal restarts in the existing SQLite database. Back up the database including its WAL/checkpoint state through an ordinary SQLite backup before deployment changes.

The bundled Hafez transcriptions came from the nine linked Persian Wikisource pages in `src/mikachan/content/hafez.json`. The bot displays the poet and stores the source URL and rights with each item, while omitting the source footer from poem cards. Wikisource page text is available under [Creative Commons Attribution-ShareAlike](https://creativecommons.org/licenses/by-sa/4.0/); the original historical poems are public domain. Extraction retained verse wording and adjusted couplet separators for the Telegram layout.

The terminal manager now has six sections, a single `/opt/Mikachan` managed root, a queue/host/storage overview and a stopped-service transient cleanup operation. Its installer and staging path were tested locally; a real systemd host and live Telegram setup remain to be accepted. User media files are not included in persistent backups.
