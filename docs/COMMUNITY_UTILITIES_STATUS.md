## Runtime setup and inputs

`BOT_TOKEN`, `OWNER_TELEGRAM_ID`, `ALLOWED_TELEGRAM_IDS` remain required. `ALLOWED_GROUP_IDS` seeds negative numeric group IDs on first database initialization, and group handling requires `PRIVATE_CHATS_ONLY=false`; the owner can subsequently use `/admin group add|remove GROUP_ID` with a confirmation. All senders must still be individually allowed. `MOMMY_TELEGRAM_IDS` is optional and must be a subset of the configured user IDs. `NASA_API_KEY` defaults to NASA's limited `DEMO_KEY`. `NAVASAN_API_KEY` optionally enables its timestamped direct feed; `NAVASAN_REFRESH_SECONDS` defaults to 28,800 to respect the published 120/month free tier in a continuously running process. `TRANSLATION_API_URL` and `TRANSLATION_API_KEY` configure an external translation service. `/admin provider fiat frankfurter|open_er_api` and `/admin provider crypto coingecko|coinpaprika` choose fixed global reference sources.

A reviewed content import is a JSON array of objects with nonempty `kind` (`poem`, `joke`, `quote`), `language`, `body`, `author`, `source`, and `rights`. The owner/operator must verify permission and attribution before import; the tool validates required fields and size, not intellectual property rights. For Hafez fortune, set `author` to `Hafez`, `Hafez Shirazi`, `حافظ`, or `حافظ شیرازی`. Content and settings survive normal restarts in the existing SQLite database. Back up the database including its WAL/checkpoint state through an ordinary SQLite backup before deployment changes.

The bundled Hafez transcriptions came from the nine linked Persian Wikisource pages in `src/mikachan/content/hafez.json`. They are attributed to Hafez and Wikisource in each bot response. Wikisource page text is available under [Creative Commons Attribution-ShareAlike](https://creativecommons.org/licenses/by-sa/4.0/); the original historical poems are public domain. Extraction retained verse wording and adjusted couplet separators for the Telegram layout.

The terminal manager now has six sections, a single `/opt/Mikachan` managed root, a queue/host/storage overview and a stopped-service transient cleanup operation. Its installer and staging path were tested locally; a real systemd host and live Telegram setup remain to be accepted. User media files are not included in persistent backups.
