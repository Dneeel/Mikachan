# Dependencies and notices

The Python project directly pins `aiogram`, `httpx`, `yt-dlp`, `gallery-dl`, `feedparser`, `ytmusicapi`, and `pydantic-settings`. The YouTube community-post extractor `yt-dlp-community-plugin` is pinned to Git commit `7966b80209c1c1355b51469f1a338c90bd8b91f9` (upstream Unlicense) in `uv.lock`. `gallery-dl` is used as a fallback for public image posts. Development tools are `pytest`, `pytest-asyncio`, `ruff`, and `mypy`. FFmpeg/ffprobe and Deno are external runtime programs. `uv` manages the isolated environment. The code is MIT-licensed (see `LICENSE`); external packages and programs retain their own upstream licenses. No third-party source code was copied into this repository.

The integrated build also pins Pillow, qrcode, zxing-cpp, jdatetime, hijridate, lottie and CairoSVG. Animated TGS rendering needs CairoSVG's system Cairo library. Tesseract is an external runtime program. Persian OCR can fetch a 3.3 MiB [Tesseract `tessdata_best` model](https://github.com/tesseract-ocr/tessdata_best) from pinned commit `e12c65a` into Mikachan's managed cache after verifying its SHA-256; this upstream project publishes the models under Apache 2.0. The host's installed English model is copied into the same managed cache so mixed text can be read. The user's image is processed locally and is not sent to the model host. Dependencies are locked in `uv.lock`; review upstream licenses and advisory metadata before production distribution.
